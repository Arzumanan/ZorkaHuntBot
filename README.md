# 🦌 Зорька — Telegram-бот помощника охотника

Бот `@ZorkaHuntBot`. Что умеет:

| Команда | Что делает |
|---|---|
| `/start`, `/help` | приветствие, меню кнопок и справка |
| `/region` | выбор региона (субъект РФ) из списка с листанием или поиском по тексту; сохраняется. **Краснодарский край и Республика Адыгея стоят первыми** |
| `/seasons` | сроки охоты в твоём регионе: 🟢 открыто / 🟡 скоро / ⚪ закрыто, по категориям (весенняя, летне-осенняя на пернатую, копытные, пушные), с источниками |
| `/location` | текущее место: геолокация или название города (геокодинг Open-Meteo) |
| `/places` | сохранённые угодья: добавить (геолокация или город + имя), удалить, выбрать «по умолчанию» |
| `/forecast` | прогноз на зорьку на завтра и сегодня: восход/закат, ветер, осадки, давление, облачность, луна, оценка дня 1–5 и активность зверя и птицы. Под сообщением можно выбрать другое угодье |
| `/activity` | активность водоплавающей, боровой дичи и копытных (1–5, утро/вечер). Это ориентировочная оценка по правилам |
| `/subscribe`, `/unsubscribe` | утренняя рассылка прогноза **только в субботу и воскресенье и только если в регионе открыт какой-то сезон** |
| `/settime ЧЧ:ММ`, `/timezone` | время рассылки (по умолчанию 05:00) и часовой пояс (по умолчанию Europe/Moscow) |
| `/checklist` | чек-лист: оружие, документы, снаряжение, еда и питьё; нажимай на пункты (✅), добавляй свои, подсказки по погоде |
| `/add_trophy`, `/journal` | журнал трофеев (по желанию), последние 10 записей |
| `/stats` | статистика журнала: выезды и трофеи, по дичи, угодьям и месяцам, лучшие месяцы (если журнал ведётся) |

Погода — [Open-Meteo](https://open-meteo.com/) (ключ не нужен). Фаза луны считается локально. Данные хранятся в SQLite (`zorka.db`).

## ⚠️ Про сроки охоты

Сроки охоты — справочная информация, а не юридический документ. Точные сроки уточняйте в региональном охотуправлении / указе губернатора.

Данные лежат в `bot/data/seasons.json`:

* `federal` — федеральные рамки по приказу Минприроды № 477 от 24.07.2020 (в ред. от 25.12.2025). Они применяются к любому региону без собственных записей.
* `regions.<код>` — записи региона. Запись с тем же `id`, что и в `federal`, заменяет федеральную.
* у каждой записи есть `confidence` (`federal`, `regional_official` — текст акта региона прочитан, `regional_reported` — по региональным СМИ и справочным сайтам, нужно проверить) и ссылка на источник из раздела `sources`.

Регионы с собственными данными сейчас: Краснодарский край, Республика Адыгея, Московская область, Тверская область (степень проверки и источники бот показывает в `/seasons`). Остальные регионы работают по федеральным рамкам, и бот прямо об этом говорит.

Формат дат: `"10-15"` — 15 октября; `"sat3-08"` — третья суббота августа; `"eom-02"` — последний день февраля; если конец раньше начала, сезон переходит на следующий год; вместо `end` можно указать `"days": 10`.
Чтобы добавить регион, допишите блок в `regions` (код региона берите из `bot/data/regions.json`) и поставьте `"verified": true`, если источники проверены. Тест `tests/test_seasons.py` проверит целостность данных.

## Запуск на Windows (Python 3.11+)

В PowerShell или cmd, в папке проекта (`E:\ZorkaHuntBot`):

```powershell
cd E:\ZorkaHuntBot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # если файла .env ещё нет; впишите BOT_TOKEN=...
python -m bot.main
```

Если в папке уже лежит готовый `.env` с токеном, команду `copy` пропустите.
Если PowerShell не даёт активировать venv, выполните один раз:
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

Остановить бота: `Ctrl+C`.

> ⚠️ Бот работает через long polling: одновременно запускайте только **один** экземпляр с этим токеном, иначе будет ошибка `Conflict: terminated by other getUpdates request`.

## Тесты

```powershell
venv\Scripts\activate
pytest
```

Тесты не ходят в сеть: ответы Open-Meteo подменены тестовым JSON (`tests/conftest.py`).

## Структура

```
bot/
  main.py            точка входа
  config.py          токен и путь к БД из .env
  db.py              SQLite: локации и журнал
  keyboards.py       кнопки меню
  utils.py           разбор дат
  data/              seasons.json (сроки охоты), regions.json (список регионов)
  handlers/          common, location, forecast (+/activity), seasons (+/region), places,
                     checklist, subscription, journal (+/stats)
  services/
    weather.py       запросы и разбор ответов Open-Meteo
    moon.py          фаза луны
    scoring.py       чистая функция оценки дня 1–5
    activity.py      чистая функция активности зверя и птицы 1–5
    seasons.py       расчёт сроков охоты по данным seasons.json
    subscription.py  чистые функции «слать ли сегодня» и «пора ли сейчас»
    scheduler.py     asyncio-планировщик утренней рассылки
    checklist.py     шаблоны чек-листа и подсказки по погоде
    stats.py         статистика журнала
    locations.py     выбор угодья для прогноза
    forecast_text.py сборка текста прогноза
tests/               pytest: scoring, moon, weather, db, utils, seasons, activity,
                     subscription, checklist, stats, сквозные сценарии хендлеров
```

## Безопасность токена

Файл `.env` в `.gitignore` и не должен попадать в репозиторий. Если токен где-то засветился, перевыпустите его в `@BotFather` (`/revoke`) и обновите `.env`.

## Идеи на потом

Ввод собственных дат сезона пользователем, больше проверенных регионов, фото к записям журнала, редактирование и удаление записей (метод `delete_trophy` в БД уже есть), CI с `pytest` в GitHub/GitLab.
